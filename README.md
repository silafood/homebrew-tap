# Homebrew Tap

Homebrew formulae for [silafood](https://github.com/silafood) tools.

## Install

```sh
brew tap silafood/tap
brew install runsteps
```

## Available Formulae

| Formula | Description |
|---------|-------------|
| [runsteps](https://github.com/silafood/runsteps) | Interactive config-driven task runner |
